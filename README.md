# 无界旗

无界旗是一款回合制策略游戏，玩家需要担任指挥官，控制棋子资源和位置以完成各种目标，例如歼灭敌人、保护据点和运送物资。在游戏中，玩家可以通过与NPC交谈来获取任务，不同的互动方式会影响剧情的发展。玩家可以通过获取金钱和经验来升级单位，探索地图的各个地点以寻找并解锁特殊单位，同时获取新的技能。

## 游戏机制

### 战斗

#### 普通单位

普通单位具有多种属性，包括防御值、视野值、召唤费用、体力值、生命值、体力回复值和士气值。

- **体力回复值**：每个完整回合结束时，体力槽会增加此值。
- **防御值**：减免大多数伤害。
- **视野值**：解除战争迷雾的范围。
- **召唤费用**：消耗指定的召唤点数让单位上场。

普通单位拥有三个资源槽：生命槽、体力槽和士气槽。

- **生命槽**：
  - 当单位的生命值降为0时，会退出战场。
  - 收到伤害时，生命值会减少。
- **体力槽**：
  - 大多数通用行动需要消耗体力。
  - 体力值为0时，无法执行行动。
  - 透支体力（例如剩余体力10点但执行消耗50点体力的动作）时，单位会进入“虚损”状态。
  - 当体力槽恢复时，若体力槽已满，单位会进入“以逸待劳”状态。

  - **虚损状态**：
    - 下一个回合的体力恢复值减半。
    - 收到的伤害增加。
    - 持续两个完整回合。
  - **以逸待劳**：
    - 下一次行动不消耗体力槽。
- **士气槽**：
  - 士气槽为空时，无法进行攻击类动作，并且可能会被部分技能直接驱赶。
  - 士气槽为满时，攻击获得加成，体力消耗减少。
  - 周围友军被击杀时，士气值会扣除。
  - 周围敌军较多时，每完整回合根据敌军数量扣除士气值。
  - 击杀周围敌军时，士气值会增加。
  - 周围友军较多时，每完整回合根据友军数量增加士气值。

### 回合

#### 召唤点数

- 每次回合开始时，玩家会获得一定数量的单位召唤点数，用于召唤单位。
- 随着回合数的增加，召唤点数的上限也会随之提升。
- 玩家可以通过占领目标和获取道具来获得额外的召唤点数。
