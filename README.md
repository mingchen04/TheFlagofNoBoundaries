# 无界旗游戏企划书

## 1. 游戏概述
### 1.1 基础信息
- **项目名称**: 无界旗
- **游戏类型**: SRPG（策略角色扮演游戏）
- **目标平台**:
  - PC (Steam)

### 1.2 核心特色
- **三维资源系统**: 生命值/体力值/士气值动态平衡
- **动态战场**: 昼夜循环与天气系统影响战斗
- **叙事驱动**: 多结局分支与角色羁绊系统

## 2. 游戏机制
### 2.1 战斗系统
#### 行动消耗表
| 动作类型 | 体力消耗 | 士气影响 |
|----------|----------|----------|
| 移动     | 1/格     | ±0       |
| 普通攻击 | 3        | +5       |
| 技能释放 | 5        | -10      |

### 2.2 状态系统
**负面状态**:
- `虚损`: 移动范围-2（体力≤0时触发）
- `恐慌`: 攻击命中率-25%（士气≤20%时触发）
- `过载`: 每回合损失5%生命值

**增益状态**:
- `以逸待劳`: 下回合行动优先（体力≥80%时触发）
- `战意昂扬`: 暴击伤害+30%
- `协同防御`: 相邻单位分担伤害

## 3. 内容设计
### 3.1 关卡设计
**战役结构**:
1. **教学关卡**（3关）
   - 基础移动教学
   - 战斗系统教学
   - 状态系统教学

2. **主线章节**（5章×6关）
   - 每章包含：
     - 4场常规战斗
     - 1场BOSS战
     - 1个特殊事件关

### 3.2 角色培养
- **等级上限**: 50级
- **转职系统**: 2次进阶机会
- **技能树**: 3系发展路线（强攻/机动/防御）
